# Review Checklist

## Scope

- 변경 범위가 한 가지 목적에 집중되어 있는가
- unrelated file이 섞이지 않았는가

## Risk

- role-based sample action visibility가 바뀌는가
- protected branch, CI, variable 영향이 있는가
- rollback 경로가 명확한가

## Evidence

- 테스트 로그 또는 스크린샷이 있는가
- MR description이 최신 상태인가

## Merge Decision

- reviewer comment가 반영되었는가
- required approval이 충족되었는가
- merge 시점이 적절한가
